## Usage

1. Open a draft invoice.
2. Click **Re-import from Attachment**.
3. Select the attachment to import from (among the invoice attachments).
4. Confirm.

### Notes

- The action is only available on **draft** invoices.
- The re-import **deletes current invoice lines** and recreates them from the selected attachment.
- Access is restricted to users in the **Invoice Re-import from Attachment** group.
